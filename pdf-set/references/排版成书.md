# 排版成书

CRITICAL: 本步骤在 OCR（以及可选的跨页脚注处理）之后执行。直接读取 `ocr-result/` 中的分页 Markdown，按页码顺序合并并排版为最终成书 Markdown。这里只处理顺序拼接、跨页断段和段落空行；不要执行标题分类、额外清理、猜测、纠错或 token 替换。

## 输入/输出

- 输入：`书籍目录/ocr-result/*.md`
- 输出：`书籍目录/书籍名.md`

## 脚本

使用 `scripts/typeset_book.py`。

默认命令：

```bash
python3 skills/pdf-set/scripts/typeset_book.py --base-dir "书籍名"
```

Windows 示例：

```powershell
python "C:\Git\playground\skills\pdf-set\scripts\typeset_book.py" --base-dir "C:\Git\playground\书籍名"
```

## 规则

1. 严格按原文顺序处理前后页内容。
2. 只读取 `ocr-result/` 顶层的 `.md` 文件，按文件名中的数字自然排序；跨页脚注生成的 `起始页-结束页.md` 也按其页码位置参与排序。
3. 如果一个文本块没有首行缩进，把它合并到上一段末尾，包括前后页之间的续段。
4. 如果一个文本块有首行缩进，把它作为新段落。
5. 普通文本块内部的硬换行直接合并，不保留单换行分段。
6. Markdown 标题行保留为单独段落，并作为硬边界；后续无缩进文本不会并入标题。
7. 删除所有包含 `🈳` 的整行。空页标记不进入成书文件，也不作为段落边界；删除后继续按前后文本的缩进规则判断是否续段。
8. 如果出现 `🀄`，该行必须单独成段，并作为硬边界；后续无缩进文本不会并入图片占位行。
9. 最终输出每段之间只保留一个空行；不允许无空行分段，也不允许多空行分段。

## 检查

运行后确认：

- 最终文件 `书籍目录/书籍名.md` 存在。
- 段落之间均为单空行。
- 成书文件中不存在 `🈳`。
- `🀄` 图片占位行没有与正文合并。
- 后续标题分类直接原地处理这个最终文件，不再回到中间合并文件。
