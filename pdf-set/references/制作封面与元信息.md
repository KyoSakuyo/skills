# 制作封面与写入 EPUB 元信息

当用户要求生成默认封面、补全书目信息、嵌入封面，或用 Calibre 整理 EPUB 元数据时，使用本流程。Calibre 会原地修改 EPUB；先备份，再写入。

## 输入与工具

- EPUB：已经完成导出的最终文件。
- 封面脚本：`scripts/make_default_cover.js`。
- Calibre CLI：`ebook-meta`；Windows 默认位置通常是 `C:\Program Files\Calibre2\ebook-meta.exe`。
- 封面脚本需要 Node.js 和 `sharp`。脚本会先加载当前 Node 环境中的 `sharp`，再尝试 Codex 工作区运行时自带的 `sharp`。

## 阶段 1：盘点与备份

1. 列出目标 EPUB，确认数量、路径和是否存在同名汇总副本。
2. 用 `ebook-meta "文件.epub"` 读取现有标题、作者、语言、日期、出版者、系列、标签、简介、ISBN和封面状态。
3. 在任何写入前复制一份原 EPUB。批处理时所有备份放进同一个有明确名称的目录，例如 `.codex-tmp/epub-before-metadata`。
4. 不覆盖已存在的备份；若需要新的恢复点，使用新的时间戳目录。

## 阶段 2：检索真实书目信息

允许联网检索。先从 EPUB 正文、原 PDF 的标题页和版权页确定原文题名、作者、译者、出版者、出版年、语言及版本线索，再搜索互联网。

来源优先级：

1. 出版社、作者或课程的官方页面，以及书内版权页。
2. 国家图书馆、大学图书馆、ISBN机构和 WorldCat 等书目目录。
3. Google Books、Internet Archive 的馆藏记录及可信书店页面。
4. 个人博客、论坛和自动聚合页面只能提供线索，不能单独证明ISBN或版本。

至少核对题名、作者、出版者、年份、语言和载体是否指向同一版本。来源冲突时不要猜；保留已证实字段，把疑点报告给用户。

简介应根据可靠来源重新概括，避免整段复制宣传文案。用户要求中文元信息时，题名、作者显示名、简介、标签和系列名使用中文；原文题名可在简介中保留。

## ISBN 规则

ISBN识别的是具体版本和载体，不是抽象作品。尽量填写真实ISBN，但准确性优先于填满字段。

- 优先使用出版社或图书馆目录中与题名、作者、出版者、年份、语言、版本和载体完全匹配的 ISBN-13。
- 同一作品的精装、平装、电子书、再版、译本通常有不同ISBN；不得互换。
- 核对ISBN校验位。若ISBN只在低可信来源出现、校验位无效或版本无法对应，不写入。
- 若当前 EPUB 是某一纸书版本的忠实数字化，且用户希望保留来源版本书目，可写该版本ISBN，并在简介中明确“据某版本数字化”。
- 若当前 EPUB 是自制译本、合编本或经过实质改编，通常没有被正式分配ISBN。此时不要把原著其他版本冒充为当前 EPUB 的ISBN；可用 `--identifier source-isbn:978...` 记录来源版本，或仅在简介中注明。
- 找不到可信ISBN时留空，不生成、不推算、不借用相近书目ISBN。

保留检索依据：记录最终采用的来源网址和关键版本字段。除非用户要求，不把长网址塞进书名或作者字段。

## 阶段 3：确定元数据

常用字段：

- `title`：正式书名；可含学年或卷次。封面书名可按用户要求省略学年，但 EPUB 元数据仍可保留。
- `authors`：多个作者使用 `&` 分隔，例如 `作者甲 & 作者乙`。
- `author-sort`：用于排序的作者名。
- `language`：使用 `zh`、`fr`、`en` 等语言代码；中外文对照版按主要阅读语言或用户要求设置。
- `date`：使用对应版本的出版日期；只有年份时不要伪造精确日，并在简介中说明版本依据。
- `publisher`、`comments`、`tags`、`series`、`index`：有可靠依据或明确编辑方案时填写。
- `isbn`：只按上一节规则填写。

批处理前建立逐书映射表，不要从文件名盲猜题名或年份。系列序号应按用户指定或实际出版顺序统一计算。

## 阶段 4：生成默认封面

封面脚本只要求作者和书名；默认输出 1200×1920 PNG。短标题优先一行，长标题优先两行，只有极端长标题才回退三行。内部线条已限制在装饰框内。

```powershell
node "skills/pdf-set/scripts/make_default_cover.js" `
  --author "雅克-阿兰·米勒" `
  --title "评估时代的精神分析" `
  --output "书籍目录/cover.png"
```

需要保留矢量源文件时增加：

```powershell
--svg "书籍目录/cover.svg"
```

生成后检查：

1. 作者和题名没有溢出或碰到左侧线框。
2. 标题没有孤立的一字行；能用可读字号排成一行时不拆成两行。
3. 内部曲线没有穿出装饰框。
4. PNG 尺寸为 1200×1920，文字已正确渲染且不是空白图。

## 阶段 5：用 Calibre 原地写入

先运行 `ebook-meta --help` 确认当前 Calibre 版本参数。PowerShell 中使用参数数组，避免标题、简介或作者名中的空格和标点被错误拆分。

```powershell
$ebookMeta = "C:\Program Files\Calibre2\ebook-meta.exe"
$epub = "书籍目录/书名.epub"
$cover = "书籍目录/cover.png"

$args = @(
  $epub,
  "--title", "评估时代的精神分析（2003–2004）",
  "--title-sort", "评估时代的精神分析（2003–2004）",
  "--authors", "雅克-阿兰·米勒",
  "--author-sort", "米勒，雅克-阿兰",
  "--language", "zh",
  "--date", "2003-10-01",
  "--comments", "中文简介",
  "--tags", "精神分析,拉康,研讨班,中法对照",
  "--series", "拉康导向",
  "--index", "20",
  "--cover", $cover
)

# 只有精确匹配且已验证时才给这个变量赋值：
$isbn = $null
if ($isbn) { $args += @("--isbn", $isbn) }

& $ebookMeta @args
if ($LASTEXITCODE -ne 0) { throw "Calibre 元数据写入失败" }
```

没有已核验ISBN时完全省略 `--isbn`。记录来源版本ISBN但不把它声明为当前 EPUB ISBN时，使用已核验的变量：

```powershell
$sourceIsbn = $null
if ($sourceIsbn) {
  & $ebookMeta $epub --identifier "source-isbn:$sourceIsbn"
}
```

批处理时逐本检查退出码，任一本失败即停止，不继续覆盖后续文件。写入原目录后，如存在用户要求的汇总目录，从已经更新的原 EPUB 重新复制，避免两份文件失去同步。

## 阶段 6：回读与验证

1. 用 `ebook-meta "文件.epub"` 回读标题、作者、语言、日期、出版者、简介、标签、系列和ISBN。
2. 抽取嵌入封面并目视检查：

```powershell
& $ebookMeta "文件.epub" --get-cover "verify-cover.png"
```

3. 检查 EPUB ZIP/OPF 中存在 `cover-image` 清单项，且对应图片资源存在。
4. 批处理时核对目标数量、封面数量和成功写入数量一致。
5. 如有汇总副本，比较原文件与副本的 SHA-256，确认完全同步。
6. 确认正文、图片、目录和原有标识符仍然存在；写元数据不应改写正文内容。

报告最终采用的题名、作者、语言、出版信息、ISBN及其来源；未能可靠确认ISBN时明确说明留空原因。
