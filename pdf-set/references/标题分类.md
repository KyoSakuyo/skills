# 标题分类

CRITICAL: 本步骤用于“排版成书”之后。目标是把最终成书 Markdown 的标题升级、降级、合并或补齐，整理成可分割、可阅读的层级；要有逻辑清晰的结构树。不要改正文，不要重新合并正文段落。你要敢于使用三级以后的标题。

## 输入/输出

- 输入：`书籍目录/书籍名.md`
- 输出：原地更新 `书籍目录/书籍名.md`
- 建议备份：写入 `书籍目录/书籍名.before-heading-classify.md`

## 阶段 1：依据目录确认正文书目

1. 先读取书内目录页，确认正文书目与顺序。
2. 对《先知书》这类结构，正文书目是目录中的各卷书：
   - 以赛亚书、耶利米书、以西结书、何西阿书、约珥书、阿摩司书、俄巴底亚书、约拿书、弥迦书、那鸿书、哈巴谷书、西番雅书、哈该书、撒迦利亚书、玛拉基书
3. 注意区分“导读中提到的书名标题”和“正文实际开始的书名标题”。导读里的书名必须留在导读层级下，不得误升为正文一级标题。

## 阶段 2：标题层级规则

总原则：书名是正文分割单位；章必须从属于书名，不能和书名同级。

- 全书书名、前言、导读、参考书目、译注者简介等前后置大块：`#`
- 导读标题：`##`
- 导读中逐卷说明的书名：`###`
- 正文书名：`#`
- 若该书有“上篇/中篇/下篇”等篇结构：
  - 篇名：`##`
  - 章名：`###`
  - 章内小标题：`####`
- 若该书没有篇结构：
  - 章名：`##`
  - 章内小标题：`###`
- 参考书目内的字母分组：`## A`、`## B` 等

正确示例：

```markdown
# 耶利米書

## 引言

## 一章

### 蒙召
```

```markdown
# 以賽亞書

## 上篇：預言集

### 一章

#### 背叛
```

错误示例：

```markdown
# 耶利米書

# 一章
```

## 阶段 3：清理 OCR 误入正文的页眉页脚标题

识别因 OCR 错误进入正文的页眉页脚标题，并删除这些重复标题；不要删除正文中真实出现的章节标题、书名标题或小标题。

常见判断方式：

- 同一标题在相邻或相近页反复出现，且位置像页首/页尾，而不是正文结构中的正常标题。
- 重复标题内容与当前章节名、书名、卷名或页眉常见内容一致，但后文没有承接为一个新的正文段落。
- 清理时只删除误入正文的重复标题行；不要改动其前后的正文内容。
- 对目录、正文实际开始处、导读中首次介绍的标题要保留，不能仅凭“标题重复”删除。

## 阶段 4：从 PDF 回查并补齐缺失标题

如果目录或正文结构显示某个标题缺失，不要只凭 Markdown 猜测。必须回到原 PDF 查找相关疑似标题文本及其位置，再决定是否回补。

注意：PDF 回查只用于确认“标题是否存在、位于哪里、应补在哪一段前后”。不得在这里根据首行缩进重新合并段落，也不得重新整理页间断行。

执行方式：

1. 找到书籍目录下的 PDF 原文；若有多个 PDF，选择与当前成书 Markdown 对应的主 PDF。
2. 用 PDF 文本提取或页面渲染检查缺失标题附近页面：
   - 优先搜索目录中的标题原文、标题关键词、章节编号、日期、课程号等。
   - 如 PDF 文本不可检索，渲染相关页图并目视检查。
3. 记录疑似标题的证据：
   - PDF 页码或图片编号。
   - 标题文本。
   - 大致位置，例如页首、页中、段前、图前。
4. 在 `书籍目录/书籍名.md` 中找到该 PDF 位置对应的 OCR 文本上下文。
5. 只在证据明确时补标题；补入的标题层级必须符合“阶段 2：标题层级规则”。
6. 不要为了补标题改写正文。只插入缺失标题行、删除误入正文的重复页眉标题，或把 OCR 已识别但未加 `#` 的标题行升级为标题。

判断标准：

- 目录列出该标题，但 Markdown 正文没有对应标题。
- PDF 中该文本以明显标题形态出现，例如独立行、字号/加粗/居中、段落前结构性位置。
- 该标题附近正文与 Markdown 中对应段落顺序一致。

不要补的情况：

- PDF 中只是在正文句子里提到该词，不是结构标题。
- 只有目录项，没有正文实际标题证据。
- 疑似页眉页脚重复标题，而非正文结构标题。


完成标题分类后直接保留原地更新的成书 Markdown；若用户接下来要替换图片，再执行 `references/图片替换.md`。

## 阶段 5：检查

执行后至少检查：

1. `# 耶利米書` 下的 `一章` 是 `## 一章`，不是 `# 一章`。
2. 有篇结构的书，如《以赛亚书》，为 `# 以賽亞書` → `## 上篇：預言集` → `### 一章`。
3. 导读中的书名为 `###`，正文中的书名为 `#`。
4. 没有连续两个以上空行。
