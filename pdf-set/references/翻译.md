CRITICAL:
- 只使用并行翻译脚本 `scripts/fasttrans.py`。
- 先提供 Windows 绝对路径命令给用户让用户自己运行；用户要求你执行命令时，你再执行。
- 若用户未指定开始/结束序号或 batch，不要擅自补 `--start`、`--end`、`--batch`；脚本会自动判断待处理文件。

## 翻译脚本说明

- 脚本：`scripts/fasttrans.py`
- Prompt：默认读取 `assets/translate_prompt.md`
- 回退 Prompt：超时回退时读取 `assets/translate_fallback_prompt.md`
- 翻译统一使用 OpenAI Python 库。
- 密钥配置：读取 `assets/secrets_openai.txt`（`base_url`、`api_key`、`model`）。

## 输入/输出

- 输入：`translate-typeset/` 中按序号命名的 Markdown 文件（如 `0.md`、`1.md`）。
- 输出：`translate-result/` 中同名文件（如 `0.md`、`1.md`）。
- 多书名输入：`--book-name "书1" "书2"` 会依次处理各书目录；同一本书未完成前，不用后一本书补足 batch。
- 多文件输入：可重复传 `--input-file`，或用 `--input-file-from` 从 UTF-8 文本文件读取多个文件路径。

## 并行与续翻逻辑

1. 扫描输入与输出目录，跳过已经完整生成的文件。
2. 对未完成文件从已有输出断点继续。
3. 最多同时处理 `--batch` 个活动文件，默认 10。
4. 活动文件完成后，立即补入同一书籍的下一个待处理文件；该书没有待处理文件后再进入下一书。
5. 单个请求默认发送 5 段，可用 `--chunk-size` 调整。
6. 如果常规双语格式请求长时间无返回，或返回 `finishReason=CONTENT_FILTER`，脚本会自动切换到回退 Prompt：只请求中文译文，再用原文文件中的原段落拼回同样的双语输出格式。
7. HTTP 500 使用带随机抖动的指数退避重试，基础等待时间依次为 5、10、20、40、60 秒；并发任务的实际等待时间会随机错开，避免同步重试。

## 常用参数

- `--base-dir`：工作区根目录。
- `--book-name`：书名子目录，可指定多个。
- `--input-dir`：输入目录。
- `--input-file`：输入文件，可重复指定多个。
- `--input-file-from`：从 UTF-8 文本文件读取输入文件路径，一行一个。
- `--output-dir`：输出目录。
- `--output-file`：输出文件；与 `--input-file` 一一对应，或省略后写入 `--output-dir`。
- `--start`：起始序号（含）。
- `--end`：结束序号（含）。
- `--chunk-size`：每次请求段落数，默认 5。
- `--batch`：最大并行活动文件数，默认 10。
- `--reasoning-effort`：GPT-5 推理强度，可选 `none`、`low`、`medium`、`high`、`xhigh`、`max`，默认 `high`。
- `--fast`：为 GPT-5 API 请求启用 Fast 服务层（`service_tier="fast"`）；默认不启用。
- `--prompt-file`：Prompt 文件路径。

## 示例

单书：

```powershell
python "C:\Git\Git\playground\skills\pdf-set\scripts\fasttrans.py" --base-dir "C:\Git\Git\playground" --book-name "焦虑"
```

多书，依次优先处理：

```powershell
python "C:\Git\Git\playground\skills\pdf-set\scripts\fasttrans.py" --base-dir "C:\Git\Git\playground" --book-name "客体关系" "精神病" "自我" "技术" --batch 15
```

指定多个文件：

```powershell
python "C:\Git\Git\playground\skills\pdf-set\scripts\fasttrans.py" --input-file "C:\Git\Git\playground\转移\translate-typeset\30.md" --input-file "C:\Git\Git\playground\转移\translate-typeset\31.md" --output-dir "C:\Git\Git\playground\转移\translate-result" --batch 2
```
