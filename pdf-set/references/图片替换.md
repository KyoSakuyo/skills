# 图片替换

CRITICAL: 本步骤用于“排版成书”及“标题分类”之后、“翻译分割”之前，把最终 Markdown 中的 `🀄` 图片占位替换为从原书页裁切出的真实插图。直接原地处理排版成书生成的 `书籍名.md`；以 PDF/OCR 分图后的页面图像为视觉真值，不用生成式工具重画。

## 目录

- 1. 备份和候选定位
- 2. 找到原书页
- 3. 用上下文锚点确认插图位置
- 4. 裁切图片
- 5. 替换 Markdown
- 6. 检查

## 输入/输出

- 输入 Markdown：`书籍目录/书籍名.md`
- 页面图像目录：`书籍目录/images/`
- 输出图片目录：`书籍目录/assets/`
- 输出结果：原 Markdown 中的 `🀄...jpg` 占位被替换为 Markdown 图片引用

排版成书阶段会删除 `🈳` 空页标记，正常输入不应再包含它。若旧成品仍有 `🈳`，先删除含该标记的整行并重新规范段落空行，再执行图片替换。

## 1. 备份和候选定位

先备份当前成书文件：

```bash
cp "书籍目录/书籍名.md" "书籍目录/书籍名.before-image-replace.md"
```

查找所有图片占位：

```bash
rg -n "🀄|\\.jpe?g" "书籍目录/书籍名.md"
```

重点识别这些形式：

- `🀄️123.jpg`
- `🀄 123.jpg`
- `🀄` 单独成段，下一段紧接 `123.jpg`
- `🀄` 所在段落后面接对应页码或 jpg 文件名

每个候选都要记录：

- Markdown 行号。
- 占位指向的 jpg 文件名或页码。
- 占位前后各 1-2 段具有辨识度的正文锚点。

不要只按 jpg 编号或出现顺序替换；同一类图像可能重复出现，OCR 分页也可能让图片占位和正文锚点错开。

## 2. 找到原书页

按占位后的 jpg 文件名，在 `images/` 中找对应页面：

```bash
ls "书籍目录/images/123.jpg"
ls "书籍目录/images/123.jpeg"
ls "书籍目录/images/123.png"
```

若页面图像不存在，停止处理该候选并报告缺失文件。不要用相邻页猜测替代。

如果占位所在段落前后文本明显对应上一页或下一页，必须同时打开相邻页面核对。最终以“前后正文锚点 + 页面视觉位置”共同决定插图来源。

## 3. 用上下文锚点确认插图位置

对每个候选，分别确认：

- 占位前最近的唯一正文片段出现在页面插图上方或附近。
- 占位后最近的唯一正文片段出现在页面插图下方或附近。
- 图题、表题、公式编号、页内短标签是否属于插图内部。

只用 OCR 文本辅助定位，不用 OCR 覆盖已经整理好的正文。若正文锚点有断行、连字、重音、空格差异，可以缩短成仍然唯一的片段再比对。

判断边界时遵守：

- 裁切完整插图、表格、公式图、箭头、标签、图内图注。
- 不裁入相邻正文、页码、页眉、页脚、脚注线和无关留白。
- 如果图注已经是图的一部分，保留在图片内；如果图注是正文段落，保留为 Markdown 文本。
- 如果图题已经作为 Markdown 标题保留在占位上方，不要把图题再次裁入图片。
- 同一页有多个图或公式时，只裁取当前占位对应的对象。若其他公式已经被 OCR 转成 LaTeX 或正文文本，不要重复裁进图片。
- 如果整页就是图片或图版，可以裁整页内容区，但仍要去掉页眉页脚和无关边距。

## 4. 裁切图片

优先保存为 PNG；照片类连续色图像可保存为 JPEG。不要生成 EMF、WMF 或其他 Office 专用格式。

建议文件名：

```text
assets/figure-page-123-01.png
assets/table-page-123-01.png
assets/plate-page-123-01.jpg
```

可用 ImageMagick 裁切：

```bash
magick "书籍目录/images/123.jpg" -crop 宽x高+X+Y +repage "书籍目录/assets/figure-page-123-01.png"
```

如果没有 ImageMagick，使用 Pillow。Pillow 的裁切框为 `(left, top, right, bottom)`，坐标原点在页面左上角，`right` 和 `bottom` 不包含在结果内：

```python
from pathlib import Path
from PIL import Image

book = Path(r"C:\path\to\book")
source = book / "images" / "123.jpg"
target = book / "assets" / "figure-page-123-01.png"

target.parent.mkdir(parents=True, exist_ok=True)
with Image.open(source) as image:
    image.crop((left, top, right, bottom)).save(
        target,
        format="PNG",
        optimize=True,
    )
```

裁切时不要缩放原页，也不要先把页面转成低分辨率预览图。直接在 `images/` 原图上裁切，保留线条和小字的原始清晰度。

### 4.1 辅助确定像素边界

先读取原图尺寸，再以目视位置估算候选区域。对于白底黑字或黑线图，可以统计灰度图中的深色像素，辅助确定实际内容所在的行列范围：

```python
from PIL import Image

with Image.open("images/123.jpg") as image:
    gray = image.convert("L")
    print(gray.size)

    active_rows = []
    for y in range(gray.height):
        dark = sum(gray.getpixel((x, y)) < 180 for x in range(gray.width))
        if dark >= 5:
            active_rows.append(y)
```

- `180` 是白底扫描页可用的初始阈值，不是固定标准；页面偏灰或线条较浅时适当调高。
- `dark >= 5` 用于忽略少量 JPEG 噪点；小公式或细线图可能需要降低。
- 把相邻活跃行合并成区间，可以区分正文、图题、图形和页码的大致纵向范围。
- 选定纵向范围后，再统计该范围内深色像素的最小和最大 `x`，得到横向内容边界。
- 像素范围只用于辅助。页码、脚注线和正文同样会被识别为深色像素，最终边界必须结合页面视觉和前后正文锚点判断。

在检测到的内容边界外保留少量白边，通常每侧约 `15-40` 像素；细箭头、上下标、括号、表格外框和倾斜线条需要更宽余量。不要贴着最外层深色像素裁切。

### 4.2 同页多图处理

如果一页包含多个图形：

1. 对照占位前后的正文，确认当前占位位于哪两个文本块之间。
2. 在原页上找到处于相同文本块之间的图形，只裁这一部分。
3. 检查该页的 OCR Markdown；已经写成 LaTeX 的公式或已经保留为正文的标签不再收入当前图片。
4. 每个独立占位生成独立图片；不要为了省事把相隔正文的多个图裁成一张大图。

### 4.3 裁切结果检查

裁切后必须按原始尺寸打开源页和裁图并对照检查：

- 图形的所有线条、箭头、括号、上下标、字母和表格边框完整。
- 没有带入正文、页码、页眉、页脚或已经保留在 Markdown 中的标题。
- 图片四周有适量白边，但没有大面积无关留白。
- 图片尺寸与预期对象相符；过窄或过矮通常表示边界截断，接近整页尺寸通常表示裁切过宽。
- 输出确实是 PNG 或 JPEG，且没有生成 EMF、WMF 或临时预览文件。

再逐张检查裁图最外圈四条边的像素颜色是否与角落背景基本一致：

```powershell
python skills\pdf-set\scripts\check_image_borders.py "书籍目录\assets"
```

- 默认只检查最外侧 1 像素，以四角像素的中位色作为纸张背景；连续至少 2 个非背景像素，或同一边累计至少 8 个散点，会标为 `FLAG`。
- 线条、箭头、文字、圆周、公式或表格边框碰到任一外边，视为疑似未截全。必须回到 `images/` 原书页，结合前后正文重新确定边界并重裁。
- 四边统一为白色或原书纸张背景色，才可作为“可能截全”的信号；这只是必要筛查，不是充分条件。即使脚本显示 `PASS`，仍须目视确认没有漏掉图外伸出的内容，也没有带入相邻正文。
- 若裁图边缘出现相邻正文的残字、半行或整行，即使四边像素统一也必须重裁，直到只保留目标图像及其内部标签。
- 禁止给已经截断的图片添加人工白边、扩展画布或涂白原始内容来通过检测；必须从原书页恢复缺失部分后重新裁切。
- 原页水印、满幅底纹或本来就延伸到对象边界的内容可能触发 `FLAG`。只有在对照原页确认图形完整后才能作为人工例外，并记录具体文件及原因；不能擅自抹除原页内容。
- 检测脚本退出码为 `1` 表示仍有候选，不等同于所有候选都确实截断；逐一目视处理或记录例外后再完成本步骤。

## 5. 替换 Markdown

把完整占位段落替换为一个图片引用：

```markdown
![](./assets/figure-page-123-01.png)
```

如果原文是：

```markdown
🀄️123.jpg
```

替换为：

```markdown
![](./assets/figure-page-123-01.png)
```

如果原文是：

```markdown
🀄

123.jpg
```

两段一起替换为一个图片引用。

只删除已经进入裁切图片内部的重复标签或图注；不要改写相邻正文，不要重新断段，不要调整标题。

## 6. 检查

完成后检查：

```bash
rg -n "🀄" "书籍目录/书籍名.md"
rg -n "!\\[\\]\\(\\.\\/assets\\/" "书籍目录/书籍名.md"
python skills/pdf-set/scripts/check_image_borders.py "书籍目录/assets"
```

通过标准：

- 所有需要替换的 `🀄` 占位都已替换；若保留，必须有明确原因。
- 每个新增图片引用的文件都存在。
- 每张图片都来自 `images/` 中对应书页或经上下文确认的相邻书页。
- 每张图片都用前后正文锚点确认过 Markdown 位置。
- Markdown 正文变化仅限占位替换和必要的重复图内标签去重。
- Markdown 中不存在遗留的 `🈳` 空页标记。
- 每张裁图都完成四边像素筛查和原页目视复核；所有 `FLAG` 都已重裁或记录为有原页依据的人工例外。
